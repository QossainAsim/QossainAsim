## 🧪 Projects & Research

### Hybrid Methane Plume Detection System 🥇
1st place, Halshanas Hackathon (Google Developer Group, BNU).
- ResNet34 classifier (F1 = 0.766) + physics-informed U-Net segmenter (IoU = 0.543) + pretrained UNet++ (Sentinel-2, Landsat 8/9, EMIT)
- Physics-based verification engine in Google Earth Engine fusing TROPOMI, ERA5 wind, and Sentinel-2/Landsat SWIR anomalies (Beer-Lambert ΔXCH₄)
- Zero false positives across 10 negative-control sites and a year-long temporal scan; validated on Korpezhe and Aliso Canyon, cross-validated against Carbon Mapper Tanager-1
- React-Leaflet dashboard, FastAPI backend, Docker on DigitalOcean

### Pakistan Flood Early Warning System
- Real-time dashboard fusing NASA SMAP, ERA5, Sentinel-1 SAR, and OpenWeather across 17 districts
- 3 soil-moisture prediction approaches validated on the 2022 floods (33M affected), **AUC = 0.93**
- Pixel-level SMI heatmaps via Google Earth Engine, climate stripes, 4-6 week advance forecasting

### Flood Mapping & Impact Analysis: South Asia
- Flood-affected zone mapping across Pakistan, India, Nepal, Bangladesh, and Bhutan, with population-density layers to quantify human exposure

### Virtual AI Doctor: MSK X-ray Co-pilot (Oxford NDORMS)
- Normal vs. abnormal detection on upper-limb X-rays (Stanford MURA, DenseNet-style CNN)
- RAG-based medical knowledge layer, clinician-review safety gating (a co-pilot, not autonomous diagnosis)
- Researching a 3D virtual doctor interface (React/Three.js) for explainable patient-facing results

### Multi-Agent Autonomous Trading System
- Five agents: port activity (vessel movements, satellite port tracking, container activity, congestion), 150+ oil-related stocks, RSS scraping + sentiment analysis, and more
- Decision-fusion orchestrator with a feedback loop over vision, time-series, and LLM-based macro agents
- Live test: about 2% return (about $20 on $1,000), used to check the orchestrator, not as a performance claim

### Personal AI Coding IDE (built for free)
- Built on OpenCode with NVIDIA free-tier models and OpenRouter
- Added a custom agent harness, DeepSeek-inspired capabilities, and an isolated sandbox where agents test their work
- Integrated NVIDIA's skill library plus 3,000+ additional skills, with agentic planning, execution, and subagents
- Added memory and cross-session memory to fix slowness on long-horizon tasks

### AI Research Tool (alternative to Consensus / ResearchRabbit / Elicit)

- Agents work continuously on one research topic for up to 10 hours
- Memory, LangGraph workflows, and web scraping for persistent, multi-stage research
